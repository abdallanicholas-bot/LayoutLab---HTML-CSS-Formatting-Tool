# LayoutLab

LayoutLab is a browser-based web design editor that lets you drag and drop elements and edit code directly. You can build web pages, arrange elements, create animations, manage multi-page projects, and export your finished designs as usable web code.

Whether you prefer visual design or working directly with HTML and CSS, LayoutLab gives you control over both.

## Features

### 1. Visual Layout Editor

Design on an interactive canvas. Choose elements and change how they look and where they sit without starting from code.

- Drag, resize, rotate, and move elements.
- Change colors, fonts, borders, spacing, shadows, and other effects.
- Use grid controls and zoom in or out.
- Select multiple elements at a time.
- Group elements together or separate them.
- Control layers with visibility and locking options.
- Use alignment guides and precise placement tools.

### 2. Elements and Components

Build layouts with a set of elements and reusable parts.

**Basic Elements**

- Text, headings, and paragraphs.
- Boxes and circles.
- Images, buttons, and links.
- Tables and dividers.
- Polylines with customizable shapes and text.

**Reusable Components**

- Navigation bars.
- Hero sections.
- Cards.
- Pricing sections.
- Login layouts.
- Footers.

### 3. Forms and Embeds

Create form layouts and embed content using the Forms panel.

- Text inputs.
- Text areas.
- Dropdown menus.
- Checkboxes.
- Radio buttons.
- Iframes and embedded content.
- HTML details and summary elements.

### 4. Motion Studio

Edit CSS animations with a visual keyframe editor.

- Build animations using keyframes.
- Change animation properties and timing.
- Preview animations before applying them.
- Apply animations to individual elements.
- Generate CSS animation code for export.

### 5. Accessibility and WCAG Auditing

Check your designs with LayoutLab's built-in accessibility auditing tools.

- Find accessibility problems.
- Show warnings next to affected elements.
- Identify WCAG violations.
- View suggested fixes.
- Apply fixes when possible.
- Review accessibility issues across your project.

Accessibility auditing is enabled by default.

### 6. Integrated Code Editor

Switch between visual editing and direct code editing.

- View generated HTML and CSS.
- Edit code directly.
- Add your own code snippets.
- Modify or delete existing code.
- Enable JavaScript editing and preview execution through Settings.
- Check code and review generated components.

Changes to your code work alongside the visual editor.

### 7. Multi-Page Project Management

Organize websites with multiple editable pages.

- Create, rename, duplicate, and delete pages.
- Move between pages.
- Reorder pages.
- Change each page's background.
- Arrange page elements in the Layers panel.
- Save and reopen entire projects.

### 8. Themes and Editor Customization

Customize the editor with built-in themes and adjustable settings.

**Available Themes**

- Light
- Dark
- Midnight
- Ocean
- Purple
- Forest
- Custom

**Additional Settings**

- Autosave preferences.
- Accessibility auditing.
- JavaScript editing controls.
- SEO settings.

### 9. Preview and Export

Check your work and export it for further development.

- Preview your website while designing.
- See how it looks on different devices.
- Export HTML and CSS.
- Export JavaScript when enabled.
- Export framework components.
- Set SEO metadata.
- Add page titles and descriptions.
- Choose favicons.

### 10. Responsive Interface

LayoutLab has an interface designed to work across different screen sizes.

- Desktop and mobile-friendly layouts.
- Collapsible panels and navigation.
- Touch-friendly controls.
- Keyboard shortcuts.
- Reduced-motion support.

## Getting Started

LayoutLab runs directly in your web browser. No installation or build process is required.

### Option 1: Download the Project

1. Download or clone this repository.
2. Extract the project files if needed.
3. Open the project folder.
4. Open `LayoutLab_Complete.html` in a web browser.
5. Start designing!

### Option 2: Clone with Git

```bash
git clone YOUR_REPOSITORY_URL
```

Then open `LayoutLab_Complete.html` in your browser.

## Saving and Managing Projects

LayoutLab provides several ways to save and manage your work.

**Project Files**

- Save projects as JSON files.
- Open saved projects.
- Save projects under different names.
- Reopen saved projects for further editing.

**Autosave Options**

| Mode | Behavior |
|---|---|
| Real-time | Saves changes as you work |
| Every 10 seconds | Saves automatically at regular intervals |
| Manual | Saves only when you choose |

Editor preferences and theme settings are also stored in browser storage.

## Project Goals

LayoutLab aims to simplify web design by combining visual editing with direct access to the underlying code.

The project focuses on three principles:

**Visual Control**

Give users an interactive workspace for designing and organizing web layouts.

**Code Flexibility**

Allow users to inspect, edit, and export the code behind their designs.

**Creative Freedom**

Provide tools for building multi-page layouts, customizing components, creating animations, and improving accessibility.

LayoutLab is designed to make building web interfaces more accessible while preserving control over the final result.
