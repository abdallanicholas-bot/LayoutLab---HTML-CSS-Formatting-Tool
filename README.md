# LayoutLab

**Design visually. Edit freely. Build without limits.**

LayoutLab is a browser-based visual web design editor that brings together drag-and-drop editing and direct code customization. Build web pages, arrange elements, create animations, manage multi-page projects, and export your designs as usable web code.

Whether you prefer visual design or working directly with HTML and CSS, LayoutLab gives you control over both.

## Features

### 1. Visual Layout Editor

Design directly on an interactive canvas. Select elements and customize their appearance and placement without starting from code.

- Drag, resize, rotate, and reposition elements.
- Customize colors, typography, borders, spacing, shadows, and effects.
- Use grid controls and adjustable zoom.
- Select multiple elements at once.
- Group and ungroup elements.
- Manage layers with visibility and locking controls.
- Undo and redo changes.
- Use alignment guides and precise positioning controls.

### 2. Elements and Components

Build layouts using a collection of editable elements and reusable components.

**Basic Elements**
- Text, headings, and paragraphs.
- Boxes and circles.
- Images, buttons, and links.
- Tables and dividers.
- Polylines with customizable shapes and text.

**Reusable Components**
- Navigation bars.
- Hero sections.
- Cards.
- Pricing sections.
- Login layouts.
- Footers.

### 3. Forms and Embeds

Create form layouts and embedded content through the dedicated Forms panel.

- Text inputs.
- Text areas.
- Dropdown menus.
- Checkboxes.
- Radio buttons.
- Iframes and embedded content.
- HTML details and summary elements.

### 4. Motion Studio

Create and customize CSS animations through a visual keyframe editor.

- Build animations with multiple keyframes.
- Customize animation properties and timing.
- Preview animations before applying them.
- Apply animations to individual elements.
- Generate CSS animation code for export.

### 5. Accessibility and WCAG Auditing

Review your designs with LayoutLab's built-in accessibility auditing tools.

- Detect potential accessibility issues.
- Display warnings beside affected elements.
- Identify WCAG-related violations.
- View suggested corrections.
- Apply automatic fixes where available.
- Review accessibility issues across your project.

Accessibility auditing is enabled by default.

### 6. Integrated Code Editor

Move between visual editing and direct code customization.

- View generated HTML and CSS.
- Edit code directly.
- Add custom code snippets.
- Modify or remove existing code.
- Enable JavaScript editing and preview execution through Settings.
- Review code checks and generated components.

Changes to your code work alongside the visual editor.

### 7. Multi-Page Project Management

Organize larger websites with multiple editable pages.

- Create, rename, duplicate, and delete pages.
- Switch between pages.
- Reorder pages.
- Customize individual page backgrounds.
- Organize page elements through the Layers panel.
- Save and reopen complete projects.

### 8. Themes and Editor Customization

Personalize the editor with built-in themes and configurable settings.

**Available Themes**
- Light
- Dark
- Midnight
- Ocean
- Purple
- Forest
- Custom

**Additional Settings**
- Autosave preferences.
- Accessibility auditing.
- JavaScript editing controls.
- SEO settings.

### 9. Preview and Export

Review your work and export it for further development.

- Preview your website while designing.
- View responsive device layouts.
- Export HTML and CSS.
- Export JavaScript when enabled.
- Export framework components.
- Configure SEO metadata.
- Set page titles and descriptions.
- Customize favicons.

### 10. Responsive Interface

LayoutLab includes an interface designed for different screen sizes.

- Desktop and mobile-friendly layouts.
- Collapsible panels and navigation.
- Touch-friendly controls.
- Keyboard shortcuts.
- Reduced-motion support.

## Getting Started

LayoutLab runs directly in your web browser. No installation or build process is required.

### Option 1: Download the Project

1. Download or clone this repository.
2. Extract the project files if needed.
3. Open the project folder.
4. Open `LayoutLab_Complete.html` in a modern web browser.
5. Start designing.

### Option 2: Clone with Git

```bash
git clone YOUR_REPOSITORY_URL
```

Then open `LayoutLab_Complete.html` in your browser.

## Saving and Managing Projects

LayoutLab provides several ways to save and manage your work.

**Project Files**
- Save projects as JSON files.
- Open previously saved projects.
- Save projects under different names.
- Reopen saved projects for further editing.

**Autosave Options**

| Mode | Behavior |
|---|---|
| Real-time | Saves changes as you work |
| Every 10 seconds | Saves automatically at regular intervals |
| Manual | Saves only when you choose |

Editor preferences and theme settings are also stored through browser storage.

## Project Goals

LayoutLab aims to simplify web design by combining visual editing with direct access to the underlying code.

The project focuses on three main principles:

**Visual Control**

Give users an interactive workspace for designing and organizing web layouts.

**Code Flexibility**

Allow users to inspect, edit, and export the code behind their designs.

**Creative Freedom**

Provide tools for building multi-page layouts, customizing components, creating animations, and improving accessibility.

LayoutLab is designed to make the process of building web interfaces more accessible while preserving control over the final result.
