# LayoutLab

**A browser-based visual layout editor for designing, customizing, and exporting web pages without writing code from scratch.**

LayoutLab is an interactive web design tool that combines a visual drag-and-drop editor with direct code editing. Create layouts, customize elements, manage multiple pages, add animations, and export your work into usable web code.

---

## Features

### Visual Layout Editor
- Drag, resize, rotate, and position elements directly on the canvas.
- Customize colors, typography, borders, spacing, shadows, and effects.
- Grid-based canvas with zoom controls.
- Multi-selection, grouping, and ungrouping.
- Layer management with visibility and locking controls.
- Undo and redo support.
- Alignment guides and positioning controls.

### Elements and Components
- Text, headings, and paragraphs.
- Boxes and circles.
- Polylines with customizable shapes and text.
- Images, buttons, and links.
- Tables and dividers.
- Reusable layout components.
- Navigation bars, hero sections, cards, pricing sections, login layouts, and footers.

### Forms and Embeds
A dedicated Forms panel allows users to create interactive form elements.

- Text inputs.
- Text areas.
- Dropdown menus.
- Checkboxes.
- Radio buttons.
- Iframes and embedded content.
- HTML details and summary elements.

### Motion Studio
Create custom CSS keyframe animations without manually writing animation code.

- Build animations using multiple keyframes.
- Customize animation properties and timing.
- Preview animations before applying them.
- Apply animations to individual elements.
- Export generated animation CSS.

### Accessibility and WCAG Auditing
LayoutLab includes a real-time accessibility auditing engine.

- Detect potential accessibility issues.
- Display warnings beside affected elements.
- Identify WCAG-related violations.
- Get suggested corrections and automatic fixes.
- Review accessibility issues across your project.

Accessibility auditing is enabled by default.

### Code Editor
Switch between visual editing and direct code editing.

- View generated HTML and CSS.
- Edit code directly.
- Add your own code snippets.
- Freely modify or remove existing code.
- Enable JavaScript editing and preview execution through Settings.
- Review code checks and generated components.

### Multi-Page Projects
- Create and manage multiple pages.
- Switch between pages.
- Customize individual page backgrounds.
- Organize elements using the Layers panel.
- Save and reopen projects.

### Themes and Customization
Choose from multiple built-in editor themes:

- Light
- Dark
- Midnight
- Ocean
- Purple
- Forest
- Custom theme

Additional settings include autosave preferences, accessibility auditing, JavaScript controls, and SEO options.

### Export and Preview
- Live website preview.
- Responsive device previews.
- Export HTML and CSS.
- Export JavaScript when enabled.
- Export framework components.
- Configure SEO metadata.
- Customize page titles, descriptions, and favicons.

### Responsive Interface
- Desktop and mobile-friendly interface.
- Collapsible panels and navigation.
- Touch-friendly controls.
- Keyboard shortcuts.
- Reduced-motion support.

## Getting Started

LayoutLab runs directly in your browser.

1. Clone or download this repository.
2. Open the project folder.
3. Open `LayoutLab_Complete.html` in your browser.
4. Start designing!

No installation, package manager, or build process is required for the standalone HTML version.

## Saving Projects

LayoutLab supports saving and reopening projects.

- Save projects as JSON files.
- Open previously saved projects.
- Save projects under different names.
- Configure automatic saving.

Available autosave options:

- Real-time.
- Every 10 seconds.
- Manual saving only.

## Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl + Z` | Undo |
| `Ctrl + Y` | Redo |

| `Ctrl + S` | Save project |
| `Ctrl + Shift + S` | Save As |
| `Ctrl + \` | Toggle panels |
| `?` | Shortcuts and help |

---

## Project Goals

LayoutLab aims to make web design more accessible by combining the flexibility of code with the convenience of a visual editor.

The goal is to give users control over both the appearance and underlying code of their projects, without forcing them to choose between visual design and manual development.
